# موقع أكاديمية أبطال المستقبل — Future Champs Academy

موقع تعريفي ثابت (HTML / CSS / JS) لأكاديمية رياضية، عربي RTL، بدون أي مكتبات أو build.

## التشغيل
افتح `index.html` في المتصفح، أو شغّل أي سيرفر ثابت داخل الفولدر.

## الأقسام
الرئيسية · إحصائيات · الرياضات (6) · ليه إحنا · البرامج حسب السن (تابات) · المدربين · جدول المواعيد (بفلتر) · الاشتراكات (شهري / ترم) · آراء أولياء الأمور · فورم الحجز (بيبعت على واتساب) · أسئلة شائعة · التواصل والخريطة.

## التعديل السريع
| عايز تغيّر | فين |
|---|---|
| رقم الواتساب | `js/main.js` ← `CONFIG.whatsapp` |
| جدول الحصص | `js/main.js` ← `SCHEDULE` |
| لون البراند | `css/style.css` ← `--accent` |
| الأسعار | `index.html` ← `data-month` و `data-term` في قسم الاشتراكات |
| العنوان والخريطة | `index.html` ← قسم `#contact` (غيّر `q=` في رابط الخريطة) |
| صور المدربين | ضيف `style="background-image:url(assets/coach1.jpg)"` على `.coach__img` وامسح الحروف |

## النشر
يشتغل مباشرة على GitHub Pages: Settings ← Pages ← Branch: `main` / root.
